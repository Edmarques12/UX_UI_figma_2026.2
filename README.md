## 🚀 Objetivo
Este repositório serve como **guia prático** os estudantes que desejam:
- Explorar ferramentas de prototipagem.  
- Utilizar kits e bibliotecas de UI para diferentes plataformas.  
- Criar paletas de cores e tipografias consistentes.  
- Incorporar ícones, animações e imagens livres em seus projetos.  
- Desenvolver protótipos funcionais e esteticamente agradáveis no **Figma**.
